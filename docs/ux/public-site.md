# SportsCam Web — UX e estrutura comercial

> Status: primeira implementação visual
> Data: 2026-10-03

## Objetivo

Site público para vender serviços e projetos de vídeo esportivo, câmeras, infraestrutura de rede e software associado.

O site não executa a configuração técnica do Engine. Ele gera interesse e leva o visitante para uma conversa/projeto.

## Mapa

Home
- Hero
- Soluções
- Tecnologia
- Onde usamos
- Como funciona
- Sobre
- Solicitação de projeto

Futuras páginas:
- /solucoes/video-esportivo
- /solucoes/cameras-ip
- /solucoes/rede
- /solucoes/edge-storage

## Funil

Home → solução/caso de uso → tecnologia/processo → solicitação de projeto → contato.

## Regras

- Não exigir login.
- Não expor detalhes internos do Engine.
- Não prometer recursos ainda não validados comercialmente.
- Não inventar métricas, clientes ou certificações.
- O CTA deve pedir projeto/orçamento, não "comprar câmera".
- O site deve explicar que hardware é parte de uma arquitetura maior.

## Responsividade

Breakpoints de referência:
- mobile: < 560px;
- tablet: 560–900px;
- desktop: > 900px.

O layout mobile deve preservar a hierarquia, reduzir a ornamentação técnica e manter CTA e formulário legíveis.
